# Security Policy

Thanks for helping keep FreeWhen and its users safe.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repo's **Security** tab and click **Report a vulnerability**. Please don't open a public issue or pull request for a security problem.

Include what you found, how to reproduce it, and what impact you think it has.

FreeWhen is a solo side project, so responses are best-effort. I'll acknowledge your report as soon as I can, keep you updated, and credit you in the fix if you'd like.

## Scope

In scope:

- The web app at `freewhen.simonperryman.co.uk`
- The API at `api.freewhen.simonperryman.co.uk`
- The code in this repository

Out of scope:

- Denial-of-service or volumetric/load testing
- Social engineering or phishing
- Third-party services FreeWhen relies on (such as Google, Neon, Vercel, and Resend) — please report those to the provider

## Testing guidelines

- Only test against calendars and accounts you created yourself. Don't access, change, or delete other users' data.
- If you come across someone else's data by accident, stop, don't keep or share it, and mention it in your report.
