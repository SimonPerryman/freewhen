What's actually changing

  • Light palette: cream + terracotta → warmer paper + deep teal accent.
  • Default calendar accent (peach) shifts to teal so unthemed calendars match the new chrome. The other 5 per-calendar accents (ocean, forest, plum, lemon, graphite) stay as-is.
  • Dark scheme is unchanged — same tokens, same accent. Only the trigger moves from @media (prefers-color-scheme: dark) to [data-color-scheme="dark"].
  • New user-controlled toggle (light / dark), persisted in localStorage.colorScheme. Initial value falls back to prefers-color-scheme. Inline blocking script in <head> prevents FOUC.
  • Per-calendar accents keep using data-theme="…" — the new toggle uses a different attribute (data-color-scheme) so the two compose.
  • Typography (Instrument Serif headings from the mock) deferred — palette ships first.
