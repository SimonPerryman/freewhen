Dark — Luma's canonical mode

Animated fill-in

On load, cells stagger from grey → terracotta with animation-delay. Reads as "people are answering right now" — the product demonstrating itself.

Wordmark with a kink

FreeWhen in serif italic. Tiny detail; instantly more memorable than monoweight DM Sans.

Dark as a peer, not a fallback

Same content, more drama. Worth marketing screenshots in dark by default — the radial gradient + grain you already have looks great.

What's actually changing

One theme column on the calendar (enum of ~6 presets) + one optional emoji. The grid heat map recolours via color-mix(in oklab, var(--t), white) — no separate palette per theme.

Cover-as-gradient, not photo

Two radial gradients + a noise overlay = a cover that feels designed without an image upload. Photo upload can come later if it's worth it.

"Best so far" pill

Surfaces the calendar's punchline above the fold. Currently you have BestDay as a separate block — promote it.

iii. Share artifact — the iMessage preview as a poster Both Partiful and Luma obsess over how a shared link looks in a message. A FreeWhen link should arrive looking like an event, not a URL.

How it lands in iMessage

Built dynamically

Next.js can render OG images with the ImageResponse API (edge route) — title, count, and a real heat-map grid generated from the calendar's actual responses. No design work per share.

The grid sells the link

The recipient sees terracotta clustering before they read a word. It says "people are answering" without copy.
